== Description ==

Display Minecraft avatars in WordPress, using the [Minepic](https://minepic.org/) service.
Avatars are automatically generated from the user's Minecraft username, or their WordPress login name if no username is set.

- Style: Settings > Discussion > Avatars > "Minepic style" (Avatar or Head).
- Username: each user sets "Minecraft username" in their profile, or on any page with the `[minepic_username_form]` shortcode.
- Fallback order: Minecraft username > login username > MHF_Steve/MHF_Alex (stable per user).
- Valid names: 3-16 characters, `A-Z a-z 0-9 _`.

== Installation ==

1. Upload the `minepic-avatars` folder to the `/wp-content/plugins/` directory.
2. Activate the plugin through the "Plugins" menu in WordPress.
3. Users can edit their profile and set their **Minecraft Username**.
